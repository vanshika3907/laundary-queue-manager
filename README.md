Laundry Queue Manager

About the Project

Laundry Queue Manager is a web-based application designed to manage laundry orders, token numbers, and pickup status. It helps make laundry management simple and organized.

Features

- Manage laundry orders
- Generate or manage token numbers
- Track laundry pickup status
- Simple and user-friendly interface

Technologies Used

- HTML
- CSS
- JavaScript

Project Files

- "index.html" - Defines the structure of the website.
- "style.css" - Provides the design and styling.
- "script.js" - Handles the website's interactive functionality.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.

Live Website

Project Objective

The objective of this project is to make laundry order management easier by organizing orders, token numbers, and pickup status.
